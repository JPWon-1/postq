# postq UI 기준

- 원래 api-hub의 정보 구조와 Postman의 컬렉션·요청·응답 배치를 따른다. 기능이나 별도의 장식 화면을 만들지 않는다.
- 탐색, 행동, 안내는 `src/i18n/{ko,en}.ts` 사전을 통해 한국어·영어로 쓴다. HTTP 메서드, URL, JSON, GraphQL, Authorization, Headers 등 기술 용어와 요청 편집 탭(Docs/Params/Body/Scripts/Tests/Settings/Cookies)은 영어로 유지한다. 같은 기능은 같은 이름을 쓴다.
- 툴바·상태 줄·패널 머리의 보조 동작은 `ToolButton`의 16px 선 아이콘과 28×28px 누름 영역으로 통일한다. 서로 다른 동작은 구분되는 모양을 쓰고, 같은 동작은 같은 아이콘을 쓴다. 트리 행 작업은 hover·키보드 포커스의 ··· 메뉴로 연다.
- 색·간격·높이·글자·모서리·그림자는 `src/app/globals.css` 토큰을 사용한다. 간격은 4/8/12/16/24px, 컨트롤 높이는 28/32/36px, 글자는 보조 12px·본문 13px·입력 14px, 메서드/메타만 11px를 쓴다.
- `ah-btn-primary`는 실행·저장, `ah-btn`는 보조 작업, `ah-action`은 행·닫기·메뉴 동작, `ah-input`은 입력에 사용한다. 강조색은 파랑, 오류는 빨강, HTTP 메서드 색은 의미를 유지한다.
- 본문은 좌측 정렬, 보조 설명은 한 문장으로 한다. 코드·값만 등폭 글꼴을 쓴다. 툴바는 줄바꿈하고 패널 본문은 독립적으로 스크롤한다. 키보드 초점은 모든 테마에서 보인다.
- 마스코트·닉네임 화면·업무 실데이터는 넣지 않는다. 데모는 `scripts/screenshots.mjs`의 로컬 시드만 쓴다.
- 변경 시 `node scripts/screenshots.mjs --audit --out <경로>`로 다크·라이트 × 1280×800/1440×900/1920×1080을 비교한다. 네이티브 파일 선택기는 headless 캡처 대상이 아니므로 앱의 진입 메뉴·선택 결과를 확인한다.

- Option 단독으로 도움말을 띄우지 않는다. 단축키 도움말은 상태바에서 연다.
- 변수 값은 가용 폭을 쓰는 자동 높이 textarea로 편집한다. 비밀값·개인값은 기본 가림, 명시적인 보기 버튼을 둔다. 칩·URL 변수·보조 패널은 공통 변수 편집 팝오버를 사용한다.
- 미저장 요청의 프로젝트 전환·탭 닫기는 웹뷰에서도 동작하는 앱 내부 저장/버리기/취소 확인을 사용한다.

- 모든 아이콘 버튼은 aria-label을 필수로 두고 공통 `TooltipButton`으로 이름을 호버·키보드 포커스 즉시(200ms 이내) 표시한다. 기본 title 툴팁에 의존하지 않는다.
- 실행·저장·cURL 복사·링크 복사·새 요청 등 주 동작, 빈 상태의 큰 버튼, 대화상자 버튼은 글자를 유지한다. 왼쪽 컬렉션/이력/실시간 탭과 섹션 이름, 요청·내용 탭·선택값·메뉴 항목은 탐색과 내용 식별을 위한 이름이므로 유지한다.

- 오른쪽 변수 패널은 요청에서 참조한 변수와 접힌 전체 변수 목록을 구분한다. 값 칸은 가용 폭을 우선 사용하며 편집 시 여러 줄로 펼친다. Enter·포커스 이탈은 저장, Esc는 취소한다. 범위 배지는 실제 저장 범위를 표시한다. 바디 머리는 `raw / JSON` 선택과 명시적인 `정리` 버튼을 사용한다.
